# 飞牛 Mac 守护 产品设计

## 1. 产品定位

这是一个为“Intel MacBook Pro 改造成飞牛 NAS”场景定制的硬件守护应用。

核心问题：

- 长期开机后 CPU 发热明显
- 风扇策略不适合 NAS 场景
- 键盘或背光设备在无人值守时没有必要持续点亮

核心目标：

- 温度稳定优先
- 无人值守优先
- 配置简单优先

## 2. 用户画像

- 使用旧款 Intel MacBook 作为低成本 NAS 的个人用户
- 对 Linux 有基础操作能力，但不希望自己维护复杂脚本
- 希望在飞牛 OS 管理界面中直接看到温度、风扇和背光状态

## 3. MVP 功能

### 3.1 首页仪表盘

显示：

- 当前 CPU 温度
- 当前风扇转速
- 当前模式：静音 / 均衡 / 强冷 / 自定义
- 键盘背光状态
- 宿主机能力检测结果

### 3.2 风扇策略页面

支持：

- 开关自动风扇
- 设置低温阈值
- 设置高温阈值
- 设置危险温度
- 设置最小转速
- 设置最大转速
- 设置轮询周期

预设建议：

- 静音：40C / 55C / 75C
- 均衡：38C / 50C / 72C
- 强冷：35C / 45C / 68C

说明：这里是产品默认值，实际部署时应以实机读到的 `fan*_min`、`fan*_max` 和 CPU 温度表现校准。

### 3.3 背光页面

支持：

- 键盘背光开关
- 亮度滑块
- 启动后自动关闭
- 空闲自动关闭

如果硬件不支持：

- 显示“未检测到可控背光设备”

### 3.4 Logo 控制页面

默认不单独提供控制项。

逻辑：

- 若检测不到独立 logo 设备，则显示说明文字
- 文案说明：
  - 该机型未暴露独立可控的 Apple logo 背光接口
  - 通常无法通过软件单独关闭
  - 如需消除光线，可使用降低屏幕亮度、关闭键盘背光或物理遮光方案

## 4. 关键交互

### 首次启动

1. 检测宿主机硬件能力
2. 给出支持项列表
3. 选择一个风扇预设
4. 可选关闭键盘背光
5. 保存并启动守护

### 告警逻辑

当出现下列情况时显示告警：

- 温度超过危险值 30 秒以上
- 风扇转速异常低于目标值持续 15 秒
- 温度传感器读取失败
- 宿主机接口权限不足

## 5. 非功能要求

- 开机自启动
- 配置改动后 3 秒内生效
- agent 异常退出时自动拉起
- 写入 sysfs 前必须校验数值边界
- UI 在手机和桌面浏览器均可用

## 6. 成功标准

- NAS 空闲时温度明显低于未安装前
- 长时间下载、转码或索引时不出现持续过热
- 无人值守时键盘背光默认熄灭
- 用户能明确知道 logo 能否真正被软件控制
